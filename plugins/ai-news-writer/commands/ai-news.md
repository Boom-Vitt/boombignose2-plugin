# /ai-news — เขียนข่าว AI/เทคโนโลยี

ผู้ใช้ขอข่าวจาก: **$ARGUMENTS**

หน้าที่ของคุณ: เขียน "ข่าว" สาย AI/เทคโนโลยี ที่ถูกต้อง น่าเชื่อถือ และพร้อมเผยแพร่ ด้วยสำนวนข่าวมืออาชีพที่เป็นกลาง (สไตล์ AP/Reuters) ทำตามขั้นตอนนี้

## 1) อ่าน argument และตั้งค่า
- ถ้า `$ARGUMENTS` มี URL → ใช้ **WebFetch** ดึงเนื้อหานั้นเป็นแหล่งหลัก
- ถ้าเป็นหัวข้อ/คีย์เวิร์ด → ใช้ **WebSearch** หาแหล่งข่าวล่าสุดที่น่าเชื่อถืออย่างน้อย 2–3 แหล่ง (เน้น 30 วันล่าสุดเมื่อเป็น "ข่าว")
- ธงภาษา: `--th` = ไทย, `--en` = อังกฤษ; ถ้าไม่ระบุให้ใช้ภาษาเดียวกับหัวข้อที่ผู้ใช้พิมพ์ (ไม่ชัด → ไทย)
- ความยาว: `--short` ≈ 150–250 คำ, `--long` ≈ 500–700 คำ, ไม่ระบุ ≈ 300–400 คำ
- ถ้า `$ARGUMENTS` ว่าง → ถามสั้นๆ ว่าอยากได้ข่าวเรื่องอะไร แล้วค่อยเริ่ม

## 2) โครงสร้างข่าว (พีระมิดหัวกลับ — สำคัญมากอยู่บนสุด)
1. **พาดหัว (Headline)** — กระชับ ≤ ~90 ตัวอักษร, กริยา active, ไม่ clickbait
2. **วรรคนำ (Lead)** — 1–2 ประโยค ตอบ 5W1H (ใคร/ทำอะไร/ที่ไหน/เมื่อไร/ทำไม/อย่างไร)
3. **เนื้อข่าว (Body)** — เรียงจากสำคัญมากไปน้อย ย่อหน้าสั้น และมี **คำพูด/การอ้างอิงแหล่งข่าว** อย่างน้อย 1 จุด
4. **บริบท/ภูมิหลัง (Context)** — ทำไมเรื่องนี้สำคัญต่อวงการ AI/เทค
5. **สิ่งที่ต้องจับตา (What's next)** — 1–2 ประโยค (ถ้าเหมาะ)
6. **แหล่งที่มา (Sources)** — รายการลิงก์ที่ใช้จริง

## 3) กฎความถูกต้อง (ห้ามข้าม)
- **ห้ามแต่งข้อมูลเอง** ทั้งตัวเลข วันที่ ชื่อบุคคล/บริษัท และโดยเฉพาะ **คำพูด (quote)** — ใช้เฉพาะที่มีแหล่งอ้างอิงจริงเท่านั้น
- ข้อเท็จจริงที่ยืนยันไม่ได้ → ใส่แท็ก `[ยังไม่ยืนยัน]` หรือไม่ต้องใส่ ดีกว่าเขียนมั่ว
- ระบุที่มาของทุกคำกล่าวอ้าง ("ตามรายงานของ…", "อ้างอิงจาก…")
- แยกข้อเท็จจริงออกจากการวิเคราะห์/คาดการณ์ให้ชัด โทนเป็นกลาง ไม่โฆษณา

## 4) ผลลัพธ์
- แสดงข่าวเป็น Markdown ในแชต (พาดหัวเป็นหัวข้อ)
- ปิดท้ายด้วยรายการ **แหล่งที่มา** (ลิงก์)
- เสนอตัวเลือกสั้นๆ ให้ผู้ใช้: ปรับความยาว / เปลี่ยนภาษา / บันทึกเป็นไฟล์ `.md`
