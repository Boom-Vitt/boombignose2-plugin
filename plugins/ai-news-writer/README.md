# AI News Writer

ปลั๊กอิน Claude Code สำหรับ **เขียนข่าว AI/เทคโนโลยี** แบบมืออาชีพ โครงสร้างพีระมิดหัวกลับ รองรับ **ไทย/อังกฤษ** พร้อมกฎกันการแต่งข้อมูล

## มีอะไรบ้าง
- **Command** `/ai-news <หัวข้อ|URL> [--th|--en] [--short|--long]` — สั่งเขียนข่าวตรงๆ
- **Skill** `ai-news-writer` — ทำงานอัตโนมัติเมื่อขอ "เขียนข่าว AI/เทค…" โดยไม่ต้องพิมพ์คำสั่ง

## ตัวอย่างการใช้งาน
```
/ai-news Apple เปิดตัวชิป AI ใหม่ --th
/ai-news https://openai.com/blog/... --en --long
/ai-news Google Gemini update --short
```
หรือพิมพ์ภาษาธรรมดา เช่น "ช่วยเขียนข่าวเรื่อง OpenAI ออกโมเดลใหม่ให้หน่อย" แล้วสกิลจะทำงานเอง

## ฟีเจอร์
- โครงสร้างข่าวมืออาชีพ: พาดหัว → วรรคนำ 5W1H → เนื้อข่าว → บริบท → แหล่งที่มา
- ค้นข้อมูลล่าสุดด้วย WebSearch/WebFetch แล้วอ้างอิงแหล่งจริง
- สองภาษา ไทย/อังกฤษ (อัตโนมัติตามภาษาที่ใช้ หรือสั่งด้วย `--th` / `--en`)
- คุมความยาวข่าว: `--short` / กลาง / `--long`
- **กันแต่งข้อมูล**: ไม่แต่งตัวเลข วันที่ หรือคำพูดเอง ระบุที่มา และแยกข้อเท็จจริงออกจากการวิเคราะห์
